# Что приготовить

Приложение, которое каждый день предлагает завтрак, обед и ужин. Оно учитывает ваши кухни, цель (похудеть, мало углеводов, больше белка) и норму КБЖУ, пересчитывает граммовку на число порций и примерно оценивает стоимость блюда. В базе 571 рецепт.

## Как запустить

Нужен Xcode 26 или новее, приложение работает на iOS 26+.

1. Скачайте репозиторий: зелёная кнопка **Code → Download ZIP** или `git clone`.
2. Откройте `ios/WhatToCook.xcodeproj`.
3. Выберите симулятор iPhone и нажмите ▶.

Чтобы поставить приложение на свой iPhone, выберите свою команду в настройках таргета на вкладке *Signing & Capabilities* (подойдёт бесплатный Apple ID) и при необходимости поменяйте Bundle Identifier. Чтобы выбор не сбрасывался после `xcodegen generate`, создайте файл `ios/Local.xcconfig` со строкой `DEVELOPMENT_TEAM = <ваш Team ID>`. Этот файл не попадает в git.

Проект собирается из `ios/project.yml` с помощью [XcodeGen](https://github.com/yonaskolb/XcodeGen). После добавления новых файлов выполните `cd ios && xcodegen generate`.

## Фото холодильника

Распознавание продуктов по фото работает через свой сервер (папка `server/`). Как его поднять и подключить к приложению, описано в [server/README.md](server/README.md). Без настроенного сервера кнопки «Сфотографировать холодильник» в приложении нет.

## Рецепты и цены

Рецепты лежат в `data/recipes/*.json`, цены — в `data/prices.json`. После правок проверьте данные и выгрузите их в приложение (нужен Node 20+):

```bash
node export-recipes.mjs
```

Скрипт проверяет каждый рецепт и наличие цен, а затем обновляет `ios/WhatToCook/Resources/recipes.json` и `prices.json`.
