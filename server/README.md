# Сервер распознавания фото

Приложение отправляет сюда фото холодильника, сервер передаёт его модели, которая понимает изображения, и возвращает список продуктов. Ключ к модели лежит только на сервере: из приложения его легко было бы достать.

Без ключа модели сервер работает в тестовом режиме и на любое фото отвечает одним и тем же списком. Так можно проверить связку приложение → сервер → HTTPS, прежде чем платить за модель.

## Запуск на VPS

Нужны Linux-сервер с открытыми портами 80 и 443 и Docker.

1. Установите Docker, если его нет:

   ```bash
   curl -fsSL https://get.docker.com | sh
   ```

2. Скачайте репозиторий и перейдите в папку сервера:

   ```bash
   git clone https://github.com/Kunderable/chto-prigotovit.git && cd chto-prigotovit/server
   ```

3. Создайте настройки:

   ```bash
   cp .env.example .env
   ```

   В `.env` укажите:
   - `DOMAIN` — адрес сервера. Своего домена не нужно: возьмите IP сервера, замените точки на дефисы и добавьте `.sslip.io`. Например, для `203.0.113.7` это `203-0-113-7.sslip.io`.
   - `APP_TOKEN` — любая длинная случайная строка, например из `openssl rand -hex 16`.

4. Запустите:

   ```bash
   docker compose up -d --build
   ```

   Caddy сам получит HTTPS-сертификат, это занимает до минуты.

5. Проверьте, что сервер отвечает. Ответ должен быть `{"ok":true,"mock":true}`:

   ```bash
   curl https://203-0-113-7.sslip.io/health
   ```

## Приложение

В файле `ios/Local.xcconfig` (он не попадает в git) допишите две строки и пересоберите приложение:

```
RECOGNIZE_HOST = 203-0-113-7.sslip.io
RECOGNIZE_TOKEN = <тот же APP_TOKEN>
```

Адрес пишется без `https://`: в xcconfig `//` начинает комментарий. В холодильнике появится кнопка «Сфотографировать холодильник».

## Модель: Yandex AI Studio

1. В [консоли Yandex Cloud](https://console.yandex.cloud) создайте каталог и сервисный аккаунт с ролью `ai.languageModels.user`, затем выпустите для него API-ключ.
2. В `.env` заполните:
   - `MODEL_API_KEY` — этот ключ;
   - `MODEL_NAME` — `gpt://<идентификатор каталога>/gemma-3-27b-it`.

   Точное имя модели и цену проверьте в консоли: список моделей у Яндекса меняется.
3. Перезапустите сервер и проверьте `/health`: теперь там должно быть `"mock":false`.

   ```bash
   docker compose up -d
   ```

Подойдёт и любой другой сервис с OpenAI-совместимым API, который принимает изображения: поменяйте `MODEL_BASE_URL`, `MODEL_NAME` и `MODEL_API_KEY`. Пример для OpenRouter есть в `.env.example`.

## Расходы и защита

- Каждое фото — платный запрос к модели. `REQUESTS_PER_HOUR` ограничивает число фото в час с одного адреса (по умолчанию 30).
- `APP_TOKEN` отсекает случайные запросы, но это не настоящая защита: токен зашит в приложение, и его можно оттуда достать. Если расходы начнут расти, следующий шаг — вход в приложение и лимит на пользователя.
- Фото на сервере не сохраняются.

## Разработка

```bash
npm test
```

Сервер без зависимостей, нужен Node 20+. Локально без Docker: `APP_TOKEN=... node src/server.mjs`. Он слушает порт 8080, а в приложении тогда пишется `RECOGNIZE_HOST = localhost:8080`.

`products.json` — список продуктов из базы рецептов. Его обновляет `node export-recipes.mjs` из корня репозитория.
